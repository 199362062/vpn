第一步：复制Clash 订阅码
安装完成后，打开Clash for Windows客户端，即可成功启动Clash小猫客户端，但是在我们导入Clash订阅码之前，还不能正常访问国外网站。
第二步：粘贴下载《Clash 配置文件》
打开Clash 主界面，选择 Profiles, 粘贴复制的《Clash 订阅码》，点击 Download 按钮，下载配置文件，导入成功后，我们就可以在窗口中找到刚才导入的新节点，点击选择对应文件即可。Clash默认的config.yaml 文件千万不要删除，删除了可能会导致Clash无法正常运行!

完成上一步，接下来。

第三步：开启代理
点击 General , 返回主页。 将 System Proxy 开启 即可启用代理。开启状态下按钮状态为绿色。
[图片]
第四步：选择节点
点击 Proxies进入代理页面，选择节点即可正常访问国外网站。

备注
在添加完订阅地址之后，需要选择一个代理节点使用，点击软件主界面左侧的 代理（Proxies） 选项卡，软件右上角代理规则处默认保持 规则（Rule） 即可，代理模式主要有以下四种：
- Rule（规则模式）：根据配置文件内的规则进行分流，部分流量使用代理，部分流量不使用（推荐此方式）
- Global（全局模式）：所有请求直接发往代理服务器
- Direct（直连模式）：所有请求直接发往目的地，即不使用代理
- Script（脚本模式）：所有请求根据脚本文件规则进行分流（不推荐无编程经验用户使用）
全局模式可能会导致国内流量也走代理访问，除了网络会变慢外，还会消耗套餐流量。规则模式的好处就是区分国内国外的流量只有在规则内的国外网站才会走代理，这样即不影响国内访问速度，又节省套餐流量，所以如果没有什么特别的需求，一般选择 规则（Rule） 即可。
然后在展开的节点组之中任意单击鼠标左键选择一个节点即可。
