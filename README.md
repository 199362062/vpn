# Clash 配置说明书

以下是使用 Clash for Windows 客户端的详细配置教程，帮助你轻松配置并访问国外网站。

---

## 第一步：复制 Clash 订阅码

1. 安装完成后，打开 **Clash for Windows** 客户端，启动程序。
2. 在我们导入 **Clash 订阅码** 之前，无法正常访问国外网站，因此需要先进行配置。

---

## 第二步：粘贴下载《Clash 配置文件》

1. 打开 **Clash 主界面**，选择 **Profiles**。
2. 粘贴复制的 **Clash 订阅码**，然后点击 **Download** 按钮。
3. 配置文件下载并导入成功后，您将能够在界面中看到新节点。
4. 选择对应的节点，点击即可连接。
   
> **注意：** 请不要删除 **Clash 默认的 `config.yaml` 文件**，否则可能导致 Clash 无法正常运行。

![步骤截图](https://example.com/path/to/your-image.jpg)

---

## 第三步：开启代理

1. 点击 **General**，返回到主页。
2. 将 **System Proxy** 开启，按钮状态会变为绿色，表示代理已启用。

![步骤截图](https://example.com/path/to/your-image2.jpg)

---

## 第四步：选择节点

1. 点击 **Proxies**，进入代理页面。
2. 选择你所需的节点，即可正常访问国外网站。

---

## 备注

### 代理模式说明

在添加完订阅地址之后，你需要选择一个代理节点。点击软件主界面左侧的 **代理（Proxies）** 选项卡，软件右上角 **代理规则** 处默认设置为 **规则（Rule）**。

代理模式主要有以下四种：

- **Rule（规则模式）**：根据配置文件内的规则进行流量分流，部分流量使用代理，部分流量不使用（推荐此方式）。
- **Global（全局模式）**：所有请求都会通过代理服务器处理。
- **Direct（直连模式）**：所有请求直接发送到目的地，不使用代理。
- **Script（脚本模式）**：根据脚本文件中的规则进行流量分流（不推荐没有编程经验的用户使用）。

> **全局模式的警告**：全局模式可能会导致国内流量也经过代理，这不仅会使网络变慢，还会消耗套餐流量。建议选择 **规则模式（Rule）**，只让国外流量通过代理，这样既不影响国内访问速度，又节省流量。

---

### 节点选择

在节点组中，任意单击左键选择一个节点即可开始使用。
